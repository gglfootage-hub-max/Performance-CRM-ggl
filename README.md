# สนามยอดขาย v3 — กรอกรายวัน รายคน + แอดมิน

## อัปเกรดจากเวอร์ชันเดิม (ทำ 2 อย่าง)

### 1) เปลี่ยนโค้ดหลังบ้านใน Google Apps Script
1. เปิด Google Sheet เดิม → Extensions → Apps Script
2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจาก `apps-script/Code.gs`
3. แก้ 2 บรรทัดบนสุด
   - `PASSCODE` = รหัสทีมที่ซุปใช้อยู่ตอนนี้ (ใส่ค่าเดิม ซุปจะได้ไม่ต้องเปลี่ยน)
   - `ADMIN_CODE` = รหัสแอดมินของคุณ (ห้ามซ้ำกับรหัสทีม)
4. กด 💾 Save → เลือกฟังก์ชัน `setup` → Run (จะได้ชีตใหม่ Config, Daily, Notes, Photos)
5. Deploy → Manage deployments → ✏️ → Version: **New version** → Deploy
   (URL เดิม ไม่ต้องแก้ config.js)

### 2) เปลี่ยนไฟล์ index.html บน GitHub
1. เข้า repo → Add file → Upload files
2. ลากไฟล์ `index.html` ตัวใหม่ไปวาง (ทับของเดิม) → Commit changes
3. **ไม่ต้องอัปโหลด config.js ใหม่** ใช้ของเดิมที่ใส่ apiUrl ไว้แล้ว
4. รอ 1–2 นาที แล้วกด Cmd + Shift + R ที่หน้าเว็บ

## ตั้งค่าครั้งแรก (แอดมิน)
1. เปิดเว็บ → กด "เปลี่ยนรหัส" ที่มุมซ้ายล่าง → ใส่รหัสแอดมิน
2. ไปหน้า **ตั้งค่า (แอดมิน)**
   - เช็กวันทำงานและวันหยุดพิเศษ
   - ใส่ชื่อซุปและเป้าทั้งเดือนของแต่ละทีม
   - กด **+ เพิ่มเซลส์** ใส่ชื่อและเลือกทีม (เว้นเป้าว่าง = แบ่งเป้าทีมให้เท่ากันอัตโนมัติ)
   - ตั้งเป้า KPI ต่อคน (โทร/วัน, Talktime/วัน, %ติดต่อได้, %Con)
3. กด **บันทึกการตั้งค่า**

## ซุปใช้งานทุกวัน
หน้า **กรอกผลรายวัน** → เลือกทีม → เลือกวันที่ในปฏิทิน → กรอกตัวเลขของเซลส์แต่ละคน → บันทึก
(กด Enter เพื่อลงไปช่องของคนถัดไปได้)

## สิทธิ์
| | ซุป (รหัสทีม) | แอดมิน |
|---|---|---|
| ดูทุกหน้า | ✅ | ✅ |
| กรอก/แก้ผลรายวัน, สรุปสัปดาห์, ใส่รูป | ✅ | ✅ |
| ตั้งเป้า ทีม รายชื่อเซลส์ วันทำงาน เป้า KPI | ❌ | ✅ |
| สร้างเดือนใหม่, ดาวน์โหลด CSV | ❌ | ✅ |

## เริ่มเดือนใหม่
หน้าตั้งค่า → "เริ่มเดือนใหม่" → เลือกเดือน → สร้าง (คัดลอกทีม รายชื่อ และเป้าไปให้) → เพิ่มวันหยุดของเดือนนั้น → บันทึก
เดือนเก่ายังเลือกดูได้จากเมนูเดือนด้านซ้าย
